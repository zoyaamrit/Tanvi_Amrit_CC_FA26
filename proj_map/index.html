BACK

My part of this project was building my own world, the rolling landscape, and writing the logic that lets the worm travel between all of our worlds.

I went back to the sine and noise function we had explored in class and and made hills using the same concept. I wanted to make them feel more alive, so one each pass of draw the hill moves per the offset and height. Balancing the math between the two was what took the longest, the plain sine function was very mechanical, so adding the noise at different scales was important.

The bigger challenge was with the connecting the character. I initially tried a boolean approach where the character switched on and off depending on what scene it was in. However, I realized that I could take advantage of the graphics layer setup and simply change where the characters were being rendered. So, if the character’s positioning exceeds the width of the current buffer, it moves to the next.

Getting the gif to animate was surprisingly challenging, it ended up being an issue in the file that I had to look up how to correct.
