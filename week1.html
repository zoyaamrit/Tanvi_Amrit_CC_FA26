PROJECT: Unsupervised Machine Hallucinations MoMA by Refik Anadol

Refik Anadol's work centers on machine processing of data, and displays the mechanic reproductions and visualisations resulting from these interpretations. In this ediiton of this project, Anadol designed the machine to process the MoMA archive and captured the 'hallucinations' induced by this data processing. In essence, this is the machine's attempt to render and receate the archive.

What I find interesting about this artwork is that how much "independence" the machine appears to possess. All the algorithms work in conjuction not to control the result of how the code works but instead capture the processing and systems of the algorithms themselves. I think this is a unique and interesting way to process large amounts of data but I'm curious about what the artist wants to bring out and emphasise through this process.
